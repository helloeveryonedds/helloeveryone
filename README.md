# helloeveryone
self_storage
1、项目背景
本系统拟实现一个餐厅的线上管理系统。该系统是为线下实体店设计的，便于
商家对自己店铺的管理和顾客自助点单，增加服务质量，以便增加营业额和口碑。
系统用户可分为顾客与店家两类，顾客主要包括订单生成与支付；店家业务较多，
除基础的菜单管理功能外，还需包含食材资源调配、人历资源配置等运营管理需求。
此外，本系统希望最终能尽量满足实际中的使用环境。
2、项目实施环境
开发环境 描述 
开发 IDE Vscode
数据库管理系统（DBMS） Progresql 17.6.1
应用服务器软件 无
建模软件 PlantUML
配置管理软件 无
测试软件 Trae
其他
运行环境 描述 
客户端硬件 必须安装 JDK 21 或更高版本
npm 或 yarn 用于管理前端依赖
服务器端硬件 Node.js 环境 (推荐 v16+)
Maven 3.6+ 用于构建后端
软件：操作系统（服务器） Windows 11
软件：操作系统（客户端） Windows 11
